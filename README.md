# معهد ماز العالي للتدريب — MAZ Higher Institute of Training (Demo)

نسخة عرض (واجهة أمامية) لموقع **معهد ماز العالي للتدريب** (الرياض رجال ونساء، جدة، بريدة). Vue 3 + Vite، عربي/إنجليزي.

## التشغيل
```bash
npm install
npm run dev
```
الرفع على Vercel: GitHub ثم Import (Build: `npm run build`، Output: `dist`).

## الأصول (`public/img/`)
من صفحتي الفرعين (رجال 4.3 من 110، نساء 4.0 من 81) على خرائط Google: معمل الحاسب، الردهة، محطات التدريب، الممرات، قاعة الاستقبال، صور برامجهم (الذكاء الاصطناعي، الأمن السيبراني، روبوت الأطفال)، وبوستر الفروع.
الشعار مرسوم SVG من علامة المعهد الذهبية (الخطوط المائلة).
مواقعهم الحالية mazsa.net و diploma.mazsa.net لا تعمل. لم أجد حساب سوشيال ظاهراً.

## المحتوى
- البرامج المعروضة فقط ما ظهر فعلاً في صورهم ومراجعاتهم: دبلوم الذكاء الاصطناعي، الأمن السيبراني، التحضير لـ CSCP، الروبوت للأطفال. الأوصاف التفصيلية مقترحة — تأكد منها.
- أرقام واتساب الفروع من بوستر المعهد (الرياض 0593203989 / 0595142046، جدة 0580949337، بريدة 0580641668). الموحد 920011779 والنسائي 920066147 من Google.
- نموذج التسجيل يرسل الطلب لواتساب الفرع المختار.

## قبل الإطلاق الرسمي
احذف `noindex` من `index.html` وشريط "نسخة عرض" من `src/App.vue`، وأضف قائمة البرامج الكاملة والمدد والاعتمادات.
